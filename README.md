# Na niskim poziomie

Code for the YouTube channel [Na niskim poziomie](https://www.youtube.com/@naniskimpoziomie).

Each mini project lives in its own folder, with a `README.md` describing what it does.

## Contents

- [arm_assembler_simple_counter](arm_assembler_simple_counter/) — a very simple counting loop in ARM64 assembly
- [arm_manual_instruction_add](arm_manual_instruction_add/) — encoding `add w1, w1, #1` into machine code by hand, using the Arm documentation
